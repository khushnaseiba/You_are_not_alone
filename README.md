# You Are Not Alone

look for the exit!

## Description
So , It's a game where you have to find the exit but as the name suggests you are not alone ,there is a ghost in the game but don't worry the background music changes when the ghost comes near, you have to find the exit and avoid the ghost to win.

### Controls

- Move: `W` `A` `S` `D` or Arrow Keys

## Getting Started

1. Install [Godot 4.7](https://godotengine.org/download/)
2. Clone the repo and open it in Godot
3. Hit Play (F5)

Or play it [in your browser](https://khushnaseiba.github.io/You_are_not_alone)
